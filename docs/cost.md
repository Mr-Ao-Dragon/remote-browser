# 成本说明

> 结论先行：本方案的成本由**实例运行时长**和**暂停实例占用**两部分构成，不按部署常驻计费。关键是把「浏览器活着的时间」压到任务实际需要的时间，而不是 Agent 进程的存活时间。

## 1. 计费对象

AGS 侧只有沙箱实例会产生资源占用：

| 状态 | 是否占资源 | 说明 |
|---|---|---|
| `RUNNING` | 是（CPU + 内存全量） | 浏览器在跑，CDP 可连 |
| `PAUSING` / `PAUSED` | 是（内存保留，CPU 释放） | 页面、登录态、localStorage 都在内存里 |
| `STOPPED` | 否 | 端口与 Token 立即失效，不可恢复 |
| 无实例 | 否 | 空闲超过本机回收窗口后就是这个状态 |

工具（`SandboxTool`）本身只是模板，不产生运行成本；部署（`Deployment`）本方案不使用，`MinInstanceCount=0` 也不会常驻。

具体单价（元/vCPU·小时、元/GiB·小时、暂停态是否减免、是否按秒计费）**以控制台和商务合同为准**，Beta 期间可能调整。本文只给计算模型和实测时长，不臆造价格。

## 2. 实测时长（2026-11-25，上海）

| 动作 | 耗时 |
|---|---|
| `StartSandboxInstance` 到 RUNNING | ≈3.5s |
| 等待 CDP 可用 + Playwright 连接 | ≈1.0s（冷启动含 502 重试） |
| `ResumeSandboxInstance` 到可操作 | ≈2.6s |
| `PauseSandboxInstance`（异步） | 进入 `PAUSING`，通常数秒内到 `PAUSED` |

单实例规格：`2 vCPU / 4 GiB`，端口 9000，`Timeout=300s`。

## 3. 计算模型

设：

- `N` = 每天任务数
- `T_work` = 单个任务浏览器实际活跃分钟数（不是用户思考时间）
- `T_idle` = 空闲回收窗口，默认 90s（`RB_IDLE_MS`）
- `R` = 2 vCPU / 4 GiB
- `P_run` = 运行态单价（元/vCPU·h 与 元/GiB·h）
- `P_pause` = 暂停态内存单价（若控制台减免则为 0）

每天运行态成本：

```
C_run = N × (T_work + T_idle/60) / 60 × (2 × P_vcpu + 4 × P_mem)
```

每天暂停态成本（只有 `persistState=true` 的会话会长时间暂停）：

```
C_pause = 暂停实例数 × 暂停小时数 × 4 × P_pause_mem
```

对比「部署常驻」基线：`MinInstanceCount=1` 时 24h × 2C4Gi，成本与任务数无关。本方案在任务稀疏时成本趋近 0，任务密集时接近基线。

## 4. 三个优化点已内置

1. **懒启动**：没有工具调用就没有实例。
2. **空闲 90s 暂停**：默认 `PAUSE`，CPU 立即释放；`persistState` 任务保留内存，其他任务可配 `RB_IDLE_ACTION=STOP` 直接归零。
3. **TTL 兜底**：`Timeout=300s`，进程崩溃最多多烧 5 分钟，不会出现 24h 常驻。

## 5. 算例（单价请替换成控制台数字）

假设 `P_vcpu=0.15 元/vCPU·h`、`P_mem=0.03 元/GiB·h`（**示例值，非官方报价**）：

- 单实例小时成本 = `2×0.15 + 4×0.03 = 0.42 元/h`
- 一个 3 分钟任务含 90s 空闲 = 4.5 分钟 → 约 `0.032 元`
- 每天 200 个任务 → 约 `6.3 元/天`
- 若暂停态内存按半价计：额外 `4×0.015=0.06 元/h·实例`

同样的任务量如果常驻 1 个实例：`0.42×24 = 10.1 元/天`，且并发上来还得加实例。

## 6. 配额与成本的关系

单地域配额：工具 10、实例 50、暂停实例 20。

- 服务端 `RB_MAX_SESSIONS=10`、`RB_MAX_TOOLS=10`、`RB_MAX_PAUSED=20` 是自我保护，防止 Agent 突发把配额打满。
- 暂停实例超过 20 个时会自动停掉最久未使用的（`src/session/manager.ts` 的 `sweep()`），避免 `LimitExceeded` 导致新任务全部失败。
- 需要更高并发时，先申请配额，再调 `RB_MAX_SESSIONS`；不要靠多地域绕。

## 7. 不产生成本的部分

- 控制面 API 调用（`StartSandboxInstance`、`AcquireSandboxInstanceToken` 等）：通常按调用次数计费或免费，量级远小于实例费用，具体看产品计费项。
- 工具与部署的元数据：不占运行资源。
- 日志：只写本机 stderr，不额外产生云上费用；如接入 CLS 则按 CLS 计费。
